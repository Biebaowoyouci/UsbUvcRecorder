USB 摄像机录制 v1.6.6 更新说明

1. 设置页新增 RTMP 直播推流：支持 RTMP/RTMPS 发布地址、4–50 Mbps 推流码率、最高 1080p/720p/跟随输入及 UAC/HDMI 嵌入音频 AAC。
2. 推流直接复用当前 UVC/采集卡 GPU 分流画面，不重复打开 USB 设备；支持断线重试、鉴权错误提示和实时上传状态。
3. 设置页新增 RTMP 网络拉流输入；启用后会作为“RTMP 网络拉流”出现在主界面“设备”列表。
4. 拉流信号支持全屏预览、90° 旋转、声音电平、主/辅录制、保存位置、分段录制、再次 RTMP 推流及 HDMI/USB-C 外接显示输出。
5. 网络流音频通过 Media3 解码为 PCM，再复用现有 AAC 录制链路；无需麦克风权限。
6. 修复竖屏输入及 90°/270° 旋转后预览画面缩小、左右或上下出现黑边的问题。
7. 预览、录制文件、RTMP 与 HDMI 输出统一改为等比铺满/中心裁切，不再通过非等比拉伸填充屏幕。
8. 90°/270° 录制继续交换编码宽高；1080p 网络输出按短边限制，竖屏保持 1080×1920，不再错误缩成 608×1080。
9. 修复多设备音频代理未完整传递目标编码宽高的问题。
10. 修复 Android 8 上调用 Android 9 专用 MediaPlayer HDMI 路由 API 可能崩溃的问题。

验证结果：
- Java 编译、完整 Debug APK 构建成功。
- 6 项单元测试全部通过。
- Android Lint 通过。
- 当前 ADB 没有在线设备，未使用真实服务器进行本轮 RTMP 收发真机验证。
